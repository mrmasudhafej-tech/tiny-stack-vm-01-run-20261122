A tiny stack virtual machine in Node 22 (stdlib only) that runs every program in the set, implementing the ISA exactly — 32-bit wrapping arithmetic, branches, calls, memory, input/output, all traps, and the step and output limits — and writes `stdout.bin` and `exit.txt` for each instance.
